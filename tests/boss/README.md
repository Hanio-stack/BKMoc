# BKMoc のブラウザテスト（ダクトの男戦・各ギミック・ステージ）

Playwright で実際にページを開き、キー入力やゲーム内の関数呼び出しでボス戦の状態遷移を確かめる。
各項目は `node:assert/strict` で期待する状態と比べ、✓/✗ を出す。1件でも ✗ があればそのテストは終了コード1で失敗し、`npm test` も失敗する。ページで例外・コンソールエラーが出た場合も失敗。

```
cd tests/boss
npm install
npx playwright install chromium   # 初回だけ（作業環境では PW_CHROMIUM=/opt/pw-browsers/chromium を指定）
npm test
```

マウスロック中の視点操作の感触などはテストできない。

テストは実時間で動くので、描画がおよそ 20fps を下回るマシンでは時間に関係する項目が落ちることがある。
そのときは描画解像度を下げて実行する（画面の大きさと□の座標は変わらない）:

```
PW_DPR=0.5 npm test
```
