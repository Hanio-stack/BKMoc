# ダクトの男戦のブラウザテスト

Playwright で実際にページを開き、キー入力やゲーム内の関数呼び出しでボス戦の状態遷移を確かめる。
各項目は `node:assert/strict` で期待する状態と比べ、✓/✗ を出す。1件でも ✗ があればそのテストは終了コード1で失敗し、`npm test` も失敗する。ページで例外・コンソールエラーが出た場合も失敗。

```
cd tests/boss
npm install
npx playwright install chromium   # 初回だけ（作業環境では PW_CHROMIUM=/opt/pw-browsers/chromium を指定）
npm test
```

| ファイル | 確かめること |
|---|---|
| t_eat.js | 捕食 → HP回復 → ライジングで取り返す（耐久が食べられた分だけ減る）／完食／食事中に殴る／スタンで腕を落とす |
| t_rise.js | 男のライジングでスローにならない／ジャストドッジ（リソース+1）・予備動作中のキック・間合いの外で防げる／振り抜いた後は間に合わない |
| t_equip.js | 奪った銃腕を装着（耐久を保持）→ 撃ってくる → 通常スタンで首の□が出ない → 斬り返すと同じ耐久で戻る／触手腕で間合いが伸びる |
| t_down.js | R1・R2 の HP0 は BOSS_DOWN を経由せず自動で逃げ、次の部屋へ進める／通常スタンでは首を斬れない／R3 の HP0 だけフィニッシャースタン（放置しても逃げない）→ ライジングの首切り・Space の蹴りのどちらでもクリア |
| t_reset.js | 捕食中・腕が飛んでいる途中・R1 自動逃走中・フィニッシャー中・頭の逃走中・弾が飛んでいる途中に G / B を押しても何も残らない（アーマー poise も0に戻る） |
| t_reg.js | 雑魚の掴みフィニッシャー・首切り・ジャスト窓・デモが今までどおり動く |
| t_asura.js | 体スキル阿修羅：ライジングに入ると追加の腕をしまい（後から生えた腕から先に）、終わるとまた順に生える／ライジングで本体の腕を付け替えても追加の腕の種類・見た目・耐久は変わらない／生え直した腕で攻撃できる |

マウスロック中の視点操作の感触などはテストできない。

テストは実時間で動くので、描画がおよそ 20fps を下回るマシンでは時間に関係する項目が落ちることがある。
そのときは描画解像度を下げて実行する（画面の大きさと□の座標は変わらない）:

```
PW_DPR=0.5 npm test
```
